# ARNPROXY Go SDK

1.1.1 sürümü. Gereksinim: Go 1.22+; standard library only.

Bu depo yalnız müşterinin API'ye bağlanmasını sağlayan istemci kodlarını içerir. Site/sunucu kodları, API anahtarları veya müşteri bilgileri içermez. SDK'nın açık kaynak olması proxy hizmetini ücretsiz yapmaz ve API erişim izni vermez. Hesap izinleri, bakiyeler, IP kısıtlamaları ve sınırlar sunucuda denetlenmeye devam eder.

Önce yalnız account isteğiyle test edin. Satın alma ve sağlayıcı işlemleri varsayılan kapalıdır. İşlem sonucu belirsizse aynı işlem anahtarıyla mevcut durumu sorgulayın; yeni sipariş veya tekrar işlem göndermeyin.

Kurulum, örnekler ve hata alanları için [README](README.md) ve [kullanım notları](USAGE.md). Rehber: https://www.arnproxy.com/account/api/docs/

Lisans: MIT, yalnız bu SDK kodları.
